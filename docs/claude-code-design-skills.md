# Claude Code Design Skills

Reference notes for setting up Claude Code so generated sites avoid the generic
"AI slop" look. Install these two skills in the desktop app / Claude Code interface.

## 1. frontend-design (official Anthropic skill)

Guides production-ready HTML/CSS/JS or React with distinctive typography, layouts,
and animations. It actively avoids generic fonts and overused patterns.

Install via marketplace:

```
/plugin marketplace add anthropics/skills
```

Then install the `frontend-design` skill.

## 2. UI/UX Pro Max (strong community skill)

Brings dozens of UI styles, 50–100+ color palettes, font pairings, and design
system intelligence.

Repo: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Install similarly: add the marketplace and install the skill (or use the
npm/global method described in the repo if preferred).
